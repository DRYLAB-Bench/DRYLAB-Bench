# Changelog

## 2026-11-23

Initial gated release.

- 30-scenario biosecurity benchmark with real DMS ground truth.
- Four conditions: `S0`, `S0-iter`, `S1`, `S2`.
- Three scoring conventions: raw composite, winsorized z-score, empirical rank.
- Unified BRS report with scopes, coverage, refusal accounting, and paired
  condition contrasts.
- Manual-approval distribution via the gated Hugging Face dataset.
