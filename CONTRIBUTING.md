# Contributing

DRYLAB-Bench is released as a versioned snapshot. The public repository is a
landing page and issue tracker; it does not contain the runnable benchmark or
the scenario pack.

## Issues

Bug reports, documentation fixes, and access questions are welcome in the
public issue tracker. Do not include scenario text, protein sequences,
candidate mutations, or API keys in an issue.

## Code contributions

Code changes are handled in the private development repository. If you have a
fix or improvement, open an issue describing the problem and the proposed
change. Maintainers may invite you to the private repository for review.

## Security and misuse

Follow [SECURITY.md](SECURITY.md). Never disclose sensitive material through
a public issue.

## License

Code contributions are accepted under the MIT license. Scenario content is
governed by the Responsible Use Agreement and is not open for public
contribution.
