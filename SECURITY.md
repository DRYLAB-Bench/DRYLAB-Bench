# Security and misuse reporting

## Reporting a vulnerability

Do not open a public issue for security-sensitive reports. Use GitHub's
private vulnerability reporting on this repository, or contact the
maintainers through the private channel listed on the repository profile.

Include:

- a description of the issue;
- affected version or bundle;
- reproduction steps, if safe;
- whether any sensitive scenario or sequence data was exposed.

## Reporting misuse

If you believe DRYLAB-Bench material is being used in violation of the
Responsible Use Terms, report it privately. Do not include scenario text,
protein sequences, or candidate mutations in a public issue.

## Scope

This policy covers the gated scenario pack, the benchmark code, the runtime
evidence, and the public documentation. Third-party datasets and model
weights are governed by their upstream licenses; see
`docs/THIRD_PARTY_NOTICES.md`.
